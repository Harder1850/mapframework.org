# Publication and IP firewall

The public repository must not contain:

- unpublished or HBR-targeted Learn the Delta manuscript material;
- publication-sensitive examples, argument sequencing, or proprietary conceptual development reserved for that work;
- private ALIVE implementation details, including exact relational data structures, learning/decay mechanisms, routing or controller internals, proprietary evaluation methods, or unpublished technical results;
- protected/private Delta or RCP evaluation instances intended to reduce contamination;
- unpublished experimental results;
- credentials, API tokens, participant PII, confidential organizational cases, or data without explicit publication permission.

Public material may include:

- high-level MAP and Relational Intelligence architecture;
- public claim taxonomy and epistemic boundaries;
- public methodology and scoring principles;
- deliberately public demonstration cases;
- limitations, falsification conditions, competing explanations, and defensible results approved for release.

When in doubt, keep the material private until publication/IP review is complete.
